# Флоу отправки скриптов в каталог

## UI-экран: "Отправить в каталог"

### Шаг 1: Валидация скрипта
```
Показывается: "Проверка скрипта..."
Проверяем:
- script.name (обязателен)
- script.events.length >= 1 (хотя бы 1 событие)
- script.actions.length >= 1 (хотя бы 1 действие)
- все события включены хотя бы одно событие (enabled !== false)
- все действия с параметрами заполнены

Если ошибка:
Alert.alert('Ошибка', 'Скрипт неполный: добавьте события и действия')
return

Если OK:
Переход к шагу 2
```

### Шаг 2: Форма отправки
```
Карточка с полями:

[Название скрипта]
(автоматически из script.name, но можно редактировать)

[Описание] (textarea)
Подсказка: "Объясните, что делает этот скрипт (100-200 символов)"

[Теги] (например: "уведомления, голос, автоматизация")
Подсказка: "Через запятую, макс 5 тегов"

[Ваше имя/ник]
Подсказка: "Как вас кредитовать в каталоге"

[Версия скрипта]
По умолчанию: 1.0
Подсказка: "Укажите версию (напр. 1.0, 1.1)"

Кнопка [Показать JSON для проверки] (развертываемая)
  → показать prettify JSON скрипта

Кнопка [Отправить в GitHub]
```

### Шаг 3: Отправка в GitHub Issue
```
При нажатии [Отправить в GitHub]:
1. Вычисляем checksumSha256(JSON.stringify(script))
2. Формируем URL для Issue:
   https://github.com/UUSR/dusi-script-catalog/issues/new?template=script_submission.yml

3. Передаём параметры в query:
   ?title=Новый скрипт: {script.name}
   &labels=script-submission

4. В body подставляем шаблон с данными скрипта

5. Открываем браузер на этом URL
   → пользователь видит Issue с предзаполненными данными
   → нажимает Submit
```

### Шаг 4: Резервный вариант (если GitHub не доступен)
```
Кнопка [Поделиться файлом]
↓
Экспортирует JSON + manifest
Открывает системное меню Share (почта, мессенджер, облако)
```

## Интеграция в экран

### Скрипты → Мои скрипты → (долгое нажатие на скрипт или кнопка меню)
```
+ Редактировать
+ Тест скрипта
+ Экспорт (текущая кнопка)
+ Отправить в каталог (новая опция)
```

Или просто кнопка рядом с кнопкой Экспорт.

## Валидация на этапе отправки

| Проверка | Условие | Сообщение об ошибке |
|----------|---------|---------------------|
| Название | name.trim().length > 0 | Укажите название скрипта |
| События | events.length >= 1 | Добавьте хотя бы одно событие |
| Действия | actions.length >= 1 | Добавьте хотя бы одно действие |
| Описание | description.trim().length > 20 | Описание должно быть не менее 20 символов |
| Ник автора | author.trim().length > 0 | Укажите ваше имя/ник |
| Версия | version >= 1.0 | Версия должна быть >= 1.0 |
